# 👋 Bem-vindo(a) à Mentoria Salesforce — Trilha Analista Júnior

Esse é o material de apoio da mentoria: cases práticos para te levar ao nível de **Analista Salesforce Júnior**, com foco em **Sales Cloud + Service Cloud** — dominando a base dessas duas nuvens, o restante do ecossistema fica muito mais fácil de aprender depois.

> 💡 Use o botão 🌙/☀️ no canto superior direito para alternar entre tema claro e escuro, e a lupa no topo da barra lateral para buscar qualquer conteúdo.

## Como funciona cada aula

Cada aula tem **3 cases**, sempre na mesma ordem:

| Case | O que é | O que você faz |
|---|---|---|
| **Case 1** | Demonstração | O mentor apresenta ao vivo, aplicado numa empresa fictícia. Você acompanha e reproduz junto. |
| **Case 2** | Demonstração (reforço) | Os mesmos tópicos do Case 1, aplicados numa segunda empresa fictícia — reforça o aprendizado por repetição. |
| **Case 3** | 🎯 Fixação | É a sua vez: mesmos tópicos, terceira empresa fictícia. Você recebe o contexto, os requisitos e os critérios de aceite — mas não o passo a passo. O objetivo é aplicar o que aprendeu nos Cases 1 e 2 com autonomia. |

**Lógica espiral:** os temas não aparecem uma vez só. Aula 1 introduz o tema → Aula 2 reforça e expande → Aula 3 reforça tudo (ou avança para um tema novo). Dentro de cada módulo, os mesmos objetos e empresas fictícias evoluem de aula em aula — então o que você constrói numa aula continua sendo usado (e ampliado) na próxima.

## Índice dos módulos

| # | Módulo | Temas |
|---|--------|-------|
| 1 | Fundamentos da Plataforma | Objetos, Tipos de campo, Layout/Record Page, Regras de validação, Relacionamentos, Campos Fórmula |
| 2 | Segurança e Acesso | Perfis, Papéis, OWD, Permission Sets, Sharing Rules |
| 3 | Automação Básica | Flow (Screen Flow, Record-Triggered básico) |
| 4 | Sales Cloud | Leads, Oportunidades/Pipeline, Contas/Contatos, Price Book |
| 5 | Service Cloud | Cases, Filas, Assignment Rules, Omni-Channel, Macros, Knowledge, SLA |
| 6 | Relatórios e Dados | Relatórios, Dashboards, Joined Reports, Data Loader/Import Wizard |
| 7 | Rotina do Analista e Gestão de Mudança | Sandbox real, Change Sets, Approval Process, case integrador final |

Nem todos os módulos estarão disponíveis desde o início — eles são liberados ao longo da mentoria, conforme o cronograma das aulas.
