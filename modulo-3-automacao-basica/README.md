# Módulo 3 — Automação Básica

## Temas do módulo

Flow (Screen Flow, Record-Triggered básico).

## Continuando a história

As mesmas 3 empresas seguem crescendo: **Nordic Móveis**, **Auto Peças Rota Norte** e **Livraria Página Viva**. Com o modelo de segurança do Módulo 2 no lugar, cada equipe reclama da mesma coisa: cadastrar um registro novo (móvel, peça, livro) manualmente, campo por campo, é lento e sujeito a erro de digitação. Você vai automatizar parte disso com Flow.

## Aulas

| Aula | Foco | Status |
|------|------|--------|
| [Aula 1](aula-1/) | Screen Flow | ✅ Pronta |
| [Aula 2](aula-2/) | Record-Triggered Flow (before-save básico) | ✅ Pronta |
| [Aula 3](aula-3/) | Combinação Screen Flow + Record-Triggered + reforço geral | ✅ Pronta |

## Lógica dos cases dentro de cada aula

Mesmo padrão dos módulos anteriores — **Case 1 = Nordic Móveis** (demonstração), **Case 2 = Auto Peças Rota Norte** (demonstração), **Case 3 = Livraria Página Viva** (fixação).

- **Aula 1:** cada empresa ganha um Screen Flow de cadastro rápido para o objeto principal do Módulo 1.
- **Aula 2:** cada empresa ganha um Record-Triggered Flow (before-save) que ajusta um campo automaticamente ao salvar.
- **Aula 3:** o Screen Flow ganha lógica condicional (mostrar/esconder campo), reforçando como as duas automações convivem no mesmo objeto — e fecha com reforço geral do módulo.
