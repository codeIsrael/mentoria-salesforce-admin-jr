# Aula 3 — Combinação Screen Flow + Record-Triggered + Reforço Geral

Última aula do Módulo 3: você vai deixar o Screen Flow da Aula 1 mais inteligente, escondendo/mostrando campos conforme o contexto (igual a lógica condicional que você já viu em regras de validação, lá no Módulo 1) — e fechar revisando as duas automações do módulo trabalhando juntas.

Pré-requisito: ter concluído as [Aula 1](../aula-1/) e [Aula 2](../aula-2/).

Os 3 cases cobrem os mesmos tópicos, cada um numa empresa fictícia diferente:

- [Case 1 — Nordic Móveis](case-1.md) *(demonstração)*
- [Case 2 — Auto Peças Rota Norte](case-2.md) *(demonstração)*
- [Case 3 — Livraria Página Viva](case-3-fixacao.md) *(fixação — sua vez de praticar)*
