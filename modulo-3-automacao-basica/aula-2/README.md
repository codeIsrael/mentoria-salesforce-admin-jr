# Aula 2 — Record-Triggered Flow (before-save básico)

Segunda aula do Módulo 3: você vai automatizar um ajuste de campo que acontece sozinho, sem tela nenhuma, todo vez que um registro é salvo — usando um Record-Triggered Flow do tipo "before-save".

Pré-requisito: ter concluído a [Aula 1](../aula-1/).

Os 3 cases cobrem os mesmos tópicos, cada um numa empresa fictícia diferente:

- [Case 1 — Nordic Móveis](case-1.md) *(demonstração)*
- [Case 2 — Auto Peças Rota Norte](case-2.md) *(demonstração)*
- [Case 3 — Livraria Página Viva](case-3-fixacao.md) *(fixação — sua vez de praticar)*
