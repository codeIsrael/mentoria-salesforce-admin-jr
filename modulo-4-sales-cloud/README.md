# Módulo 4 — Sales Cloud

## Temas do módulo

Leads, Oportunidades/Pipeline, Contas/Contatos, Price Book.

## Continuando a história

As mesmas 3 empresas — **Nordic Móveis**, **Auto Peças Rota Norte** e **Livraria Página Viva** — agora vão usar o Salesforce para o que ele foi originalmente construído: vender. Diferente dos módulos anteriores, aqui você trabalha com os **objetos padrão** do Sales Cloud (Lead, Account, Contact, Opportunity, Product2, Pricebook2) em vez de objetos customizados — mas o raciocínio de negócio continua sendo o mesmo de cada empresa que você já conhece dos módulos 1 a 3.

## Lógica dos cases dentro de cada aula

Mesmo padrão dos módulos anteriores — **Case 1 = Nordic Móveis** (demonstração), **Case 2 = Auto Peças Rota Norte** (demonstração), **Case 3 = Livraria Página Viva** (fixação).

- **Aula 1:** cada empresa captura e qualifica um Lead, e converte em Account + Contact + Opportunity.
- **Aula 2:** cada empresa organiza os dados de Account/Contact e avança a Opportunity por um pipeline de estágios.
- **Aula 3:** cada empresa cria um Price Book com produtos e adiciona itens à Opportunity — fechando o ciclo completo: Lead → Account/Contact → Opportunity → Price Book.
