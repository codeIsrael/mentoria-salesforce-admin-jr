Pré-requisito: ter concluído a [Aula 1](../aula-1/) (Lead convertido, gerando Account/Contact/Opportunity).

Os 3 cases cobrem os mesmos tópicos, cada um numa empresa fictícia diferente:

- [Case 2 — Auto Peças Rota Norte](case-2.md) *(demonstração)*
- [Case 3 — Livraria Página Viva](case-3-fixacao.md) *(fixação — sua vez de praticar)*
