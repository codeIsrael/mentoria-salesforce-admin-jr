# Aula 1 — Perfis e Papéis

Primeira aula do Módulo 2: você vai criar um Perfil customizado (controlando o que cada tipo de usuário pode fazer) e uma Hierarquia de Papéis (a estrutura organizacional que, mais pra frente, vai controlar o que cada um enxerga).

Os 3 cases cobrem os mesmos tópicos, cada um numa empresa fictícia diferente:

- [Case 1 — Nordic Móveis](case-1.md) *(demonstração)*
- [Case 2 — Auto Peças Rota Norte](case-2.md) *(demonstração)*
- [Case 3 — Livraria Página Viva](case-3-fixacao.md) *(fixação — sua vez de praticar)*
