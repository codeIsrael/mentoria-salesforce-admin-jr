# Aula 2 — Relacionamentos + Regras de Validação (expansão)

Segunda aula do Módulo 1: você vai conectar objetos entre si com relacionamentos (Lookup e Master-Detail) e expandir suas regras de validação para considerar campos de um objeto relacionado.

Pré-requisito: ter concluído a [Aula 1](../aula-1/), já que os cases aqui evoluem os mesmos objetos criados lá.

Os 3 cases cobrem os mesmos tópicos, cada um numa empresa fictícia diferente:

- [Case 1 — Nordic Móveis](case-1.md) *(demonstração)*
- [Case 2 — Auto Peças Rota Norte](case-2.md) *(demonstração)*
- [Case 3 — Livraria Página Viva](case-3-fixacao.md) *(fixação — sua vez de praticar)*
